# Cursor

## Why learn this

How to use Cursor to study this book: the window, chat modes, `@` files, quizzes, the study loop, then intermediate study/edit habits, then advanced rules, media honesty, and book maintenance. Not a general IDE or Git course.

Bands: **lessons 01–05 beginner** → [beginner project](project-beginner.md) → **06–10 intermediate** → [intermediate project](project-intermediate.md) → **11–15 advanced** → [advanced project](project-advanced.md). Each lesson file has its own `level`. Projects are not numbered as lessons.

## Prerequisites

- None to start. This book is already open in Cursor.
- Intermediate assumes 01–05. Advanced assumes 06–10.

## Glossary

Key terms introduced across lessons — add to this as lessons are written.

| Term | Definition | First seen |
|------|------------|------------|
| IDE | The app that holds files, the editor, and (in Cursor) chat in one window | [Lesson 01](lesson-01.md) |
| Explorer | The file list, usually on the left | [Lesson 01](lesson-01.md) |
| Editor | The middle area where an open file is shown | [Lesson 01](lesson-01.md) |
| Agent chat | The panel where you talk to the agent | [Lesson 01](lesson-01.md) |
| Ask | Chat that answers questions without rewriting book files | [Lesson 02](lesson-02.md) |
| Agent | Chat that can create and edit files when you ask | [Lesson 02](lesson-02.md) |
| Plan | Chat that designs the steps first, before (or instead of) doing the work | [Lesson 02](lesson-02.md) |
| `@` mention | Typing `@` in chat and picking a file so the agent is told to use it | [Lesson 03](lesson-03.md) |
| Context | The files and text the agent is looking at for this message | [Lesson 03](lesson-03.md) |
| Quiz | Questions one at a time from a lesson’s objectives; you try before the key | [Lesson 04](lesson-04.md) |
| Learning path | The status table (⬜ / 🟡 / ✅) in this subject’s index.md | [Lesson 04](lesson-04.md) |
| ASK.md | Copy-paste prompts at the book root | [Lesson 04](lesson-04.md) |
| Study loop | Read → `@` quiz → check index → choose next | [Lesson 05](lesson-05.md) |
| Stuck | You cannot answer, chat and files disagree, or the next file is missing | [Lesson 05](lesson-05.md) |
| Mixed intent | One message that wants two outcomes, such as a quiz and an index edit | [Lesson 06](lesson-06.md) |
| Mode switch | Changing Ask, Agent, or Plan and sending the request again | [Lesson 06](lesson-06.md) |
| Multi-file `@` | Attaching more than one file to the same message | [Lesson 07](lesson-07.md) |
| Wrong attachment | `@` on a file that does not contain what you asked about | [Lesson 07](lesson-07.md) |
| Live quiz | Questions in chat, one at a time; you answer before the key | [Lesson 08](lesson-08.md) |
| Mixed review | A short quiz from more than one lesson | [Lesson 08](lesson-08.md) |
| Shaky objective | A learning objective you missed or guessed | [Lesson 08](lesson-08.md) |
| Small edit | A bounded change to a file that already exists | [Lesson 09](lesson-09.md) |
| New lesson file | A new `lesson-0X.md` (or project file), not a whole new subject | [Lesson 09](lesson-09.md) |
| Dashboard | This subject’s index.md used as a status board | [Lesson 10](lesson-10.md) |
| Gap list | Media inventory and `missing` slots; later work, not a broken lesson | [Lesson 10](lesson-10.md) |
| Attached context | Files and text included on this message via `@` | [Lesson 11](lesson-11.md) |
| Workspace search | The agent looking through the folder without a specific `@` | [Lesson 11](lesson-11.md) |
| Tutoring constraints | HOW-TO-TUTOR.md (and ASK.md as prompt catalog) for this book | [Lesson 11](lesson-11.md) |
| Learning-path contract | Subject index table: one row per planned lesson, ⬜ until work starts | [Lesson 12](lesson-12.md) |
| Batch write | Generating many lesson files in one go; only if the learner asked for the whole set | [Lesson 12](lesson-12.md) |
| Media slot | Video, audio, image, or diagram on every lesson; never deleted to hide a gap | [Lesson 13](lesson-13.md) |
| Honest `missing` | The word `missing` meaning no real asset yet | [Lesson 13](lesson-13.md) |
| Housekeeping | Index updates that follow a lesson change | [Lesson 14](lesson-14.md) |
| Maintenance prompt | An ASK.md snippet to update tables on purpose | [Lesson 14](lesson-14.md) |
| Book index | Root index.md listing subjects | [Lesson 15](lesson-15.md) |
| Search vs invent | Find a real path or say there is no lesson; never fabricate a path | [Lesson 15](lesson-15.md) |
| Deliverable | The observable result of a project | [Beginner project](project-beginner.md) |
| Verified edit | A file change confirmed by opening the file | [Intermediate project](project-intermediate.md) |
| Constraint attachment | `@HOW-TO-TUTOR.md` so this book’s rules apply | [Advanced project](project-advanced.md) |
