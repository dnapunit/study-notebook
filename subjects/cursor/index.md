# Cursor

## Why learn this

How to use Cursor to study this book: the window, chat modes, `@` files, quizzes, and a full study loop. For anyone who already has this folder open and wants the chat to help, not a general IDE or Git course.

## Prerequisites

- None. This book is already open in Cursor.

## Glossary

Key terms introduced across lessons — add to this as lessons are written.

| Term | Definition | First seen |
|------|------------|------------|
| IDE | The app that holds files, the editor, and (in Cursor) chat in one window | [Lesson 01](lesson-01.md) |
| Explorer | The file list, usually on the left | [Lesson 01](lesson-01.md) |
| Editor | The middle area where an open file is shown | [Lesson 01](lesson-01.md) |
| Agent chat | The panel where you talk to the agent | [Lesson 01](lesson-01.md) |
| Ask | Chat that answers questions without rewriting book files | [Lesson 02](lesson-02.md) |
| Agent | Chat that can create and edit files when you ask | [Lesson 02](lesson-02.md) |
| Plan | Chat that designs the steps first, before (or instead of) doing the work | [Lesson 02](lesson-02.md) |
| `@` mention | Typing `@` in chat and picking a file so the agent is told to use it | [Lesson 03](lesson-03.md) |
| Context | The files and text the agent is looking at for this message | [Lesson 03](lesson-03.md) |
| Quiz | Questions one at a time from a lesson’s objectives; you try before the key | [Lesson 04](lesson-04.md) |
| Learning path | The status table (⬜ / 🟡 / ✅) in this subject’s index.md | [Lesson 04](lesson-04.md) |
| ASK.md | Copy-paste prompts at the book root | [Lesson 04](lesson-04.md) |
| Study loop | Read → `@` quiz → check index → choose next | [Lesson 05](lesson-05.md) |
| Stuck | You cannot answer, chat and files disagree, or the next file is missing | [Lesson 05](lesson-05.md) |
